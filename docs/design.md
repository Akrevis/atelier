---

## 一、定位

> **让 AI 的输出可学——从「给你结果」变成「给你理解」。**

**责任边界（已定）**：AI 负责讲清楚；**用户的理解能力不是 AI 要管的变量**。主导权在用户——用户刨根问底，AI 再讲。AI 不做验收官姿态，不主动出题。

---

## 二、问题分析（这个包为什么存在）

拿 AI 学习，相比「看书 + 自己练」：

**得到**：零成本无限追问 · 按背景定制类比 · 即时答案

**失去**：
| 丢的 | 表现 |
|---|---|
| 大纲 | AI 是响应式的，只答你问的。你问的范围 = 你知道自己不知道的范围 |
| 图 | 默认吐线性文字，结构性知识失真 |
| 难度梯度 | 对新手和专家可能给同一段话 |
| **挣扎** | 成本为零的捷径人一定会走，而挣扎正是记忆编码的必要环节 |

**AI 独有的新伤害**：**它能替你做**。书不能。于是产出物出来了、能力没长，而且你以为长了。

**实证依据**：Anthropic 研究（52 名初级工程师学 Trio 库）——用 AI 组测验 50%，手写组 67%。更精确的一刀：**用 AI 做概念性提问的人 65%+，让 AI 代写代码的人不到 40%**。

## 三、双模式（已定）

| | 日常模式 | 沉浸模式 |
|---|---|---|
| 开启 | 默认开 | 主动开启 |
| 作用域 | 全局 | 局部（某目录/项目） |
| 时间尺度 | 一次对话 | 数周~数月 |
| 状态 | 无状态 | 计划文档 + 错题本 + 复习队列 + 进度 |

**硬约束**：**沉浸模式不激活时必须完全不存在**——不加载、不注入、不提示、不问「要不要开启学习模式」。参照 groundwork「没有标记文件就完全静默」。

## 四、日常模式（待定稿）

### 已定

- **不用 output-styles**。三条理由：跨 agent 会绑死 / 全局单选会占位 / 要求用户改配置违反「装上就用，卸载就干净」
- **分层交付**：默认从最浅开始，每层结尾给**追问菜单**，用户往下点。深度是协商出来的，不是 AI 预判的
- **追问菜单**（借鉴 eli5）：每次讲完列出 2~3 个具体可深入方向。这是对「用户不知道该问什么」的正面解法
- **eli5 的价值**是内容精简、通俗易懂 + 追问菜单，**不是**把所有讲解降到 ELI5 深度

### 讲解顺序（沿用 concept-explanation）

痛点开场 → 隐喻锚定 → 设计取舍 → 串联体系 → 可迁移框架。分段交付，讲 1~2 步就停。

**不启用深度讲法**：纯约定 / 原始事实 / 纯形式定义 / 审美判断——强行套「背景痛点」会虚构不存在的历史动机。

### 复述验收（已改写，比原 skill 宽松）

> **判据：如果照你说的这套去做决策，不会做错——就算过。**

| 算核心（错了要纠） | 算细节（错了不打回） |
|---|---|
| 解决什么问题 | 具体参数值、函数名 |
| 大致怎么解决 | 步骤精确顺序 |
| 关键取舍/代价 | 用词是否专业 |

**反模式（写死）**：不许因为用词不精确就打回。说「把数据存起来」不该纠正成「持久化」。意思对就过，顶多顺带提一句，**不重讲、不复述第二遍**。

### 写码前讲思路

写码前先讲实现/数据流/边界，讲完停。TDD 可配置（TDD / 写完再测 / 混合 / 不测）。数据流日志不怕冗余，收尾问要不要清理。

**git 存档不进包**——它是全局 CLAUDE.md 的无条件底线，进包卸载即失效。

### 卡壳解锁（三档，已定）

三件套（骨架 + 失败测试 + 试过两个方向）的前提错了：它假设「你会写、只是卡在细节」，但学新东西时的真实状态是**不知道从哪下笔**。

理论依据：**样例效应**（对新手，给完整样例+讲解比让他摸索更有效）+ **专长逆转效应**（对新手有效的支架对熟手是累赘，反之亦然）。

| 状态 | 判据 | 给什么 |
|---|---|---|
| **真不会** | 说不出「这东西大概要干什么」 | **完整样例 + 数据流讲解** |
| **卡细节** | 说得出思路，写不出来 | 提示 / 伪代码骨架，不给完整实现 |
| **懒得想** | 明显能说清但直接要代码 | 才用三件套 |

**判断方式**：AI 先问一句「这个东西大概要做什么，你能说个方向吗」。说不出来就是第一档，直接给样例，不用交任何东西。

**唯一硬要求**：**样例给完之后，关掉它自己重写一遍**。worked example 后面必须跟独立练习，否则只是读了一遍代码。

## 五、画板机制（已定）

| 环节 | 机制 |
|---|---|
| 默认呈现 | **ASCII**，AI 按「能画就画」自动出，零断点 |
| 注解 | **标签级**（贴在箭头/节点旁），不允许图画完另起一大段复述 |
| 撑不住时 | AI **建议**、不自动生成；用户敲 `/palette` 触发 |
| 存储 | 单文件 `palette.html`，项目级/全局级由 AI 按内容类型自动判 |
| 复看 | 同会话内多图做成 tab 切换 |
| 生命周期 | **按会话清空**，新会话第一次 `/palette` 重置回单标签 |

**判定顺序**：先判「能不能画」（图 vs 文字）→ 再判「ASCII 撑不撑得住」（≤8 节点/简单结构走 ASCII，否则 HTML）。用户说「没看懂」是误判时的兜底，不是主入口。

**裸 Mermaid 直接毙**——Claude Code 终端不渲染，用户看到的是源码，比纯文字更难读。Mermaid 只有进 HTML/Artifact 才成立。

**原则：图在前，不在后**。图承担全局，文字降为注解，总量下降。反过来则是冗余。

## 六、沉浸模式（待拆解）

四阶段流水线：

| 阶段 | 动作 | 产出 |
|---|---|---|
| 立项 | 说需求 → 分析目标/标准 → **摸底测水平** → **联网搜真实资料** → 问可用时间 → 综合 | 学习计划文档 |
| 执行 | 分阶段推进 / 卡壳三档 / 测试策略可配置 | 代码、练习 |
| 验收 | 分阶段考核 | 错题本 |
| 复盘 | 按到期重考旧知识点 | 复习记录 |

### 已定

- **大纲必须有锚**：AI 可以做大纲，但必须锚在外部可验证材料上（JD、官方文档目录、标准、真实课程结构），**不许凭训练记忆直吐**
- **时间预算诚实化**：第一次立项 AI 没有依据，只能粗估并**明确标注「通用经验估计，误差可能很大」**；第二阶段起用实际耗时校准
- **复习调度用 SM-2 式反馈控制，不画曲线**：每个知识点独立跟踪，答对 → 间隔×系数，答错 → 重置。艾宾浩斯只用来给初始间隔一个起点
- **状态存项目目录的文件里**，不用 memkeep（语义不匹配 + 包不得依赖包）

### 学习方法落地性（已判）

| 方法 | 落地性 |
|---|---|
| 费曼 | ✅ **已有**——复述闭环就是费曼 |
| 康奈尔笔记 | ✅ 可做笔记模板，与「纯 Markdown」偏好兼容 |
| SQ3R | ⚠️ 部分——它是读材料的方法；可迁移的是「先提问再学」和「主动回忆」 |
| 西蒙 | ⚠️ 只留「目标拆分」 |
| 番茄 | ❌ AI 无法计时、无法主动打断 |

> **西蒙学习法的事实纠正**：「6个月精通任意领域」不是 Herbert Simon 的观点，是中文互联网的营销化改写。Simon 的实际结论相反——专业能力约需 10 年/数万小时（「一万小时定律」的源头）。这个假承诺**会毒化时间预算模块**，不许写进包。

## 七、硬约束（继承 AGENT-PACKS.md）

1. **装上就用，卸载就干净**——不要求用户改 CLAUDE.md 或 settings.json
2. **不得依赖任何其他包**——包括 memkeep、groundwork、rodbv/socratic-skills
3. **每个分支/检查/规则必须能说出真实触发场景**——说不出就删
4. **不阻断 ≠ 不告知**——静默失败必须有同路径自检
5. **沉浸模式不激活时完全静默**（本包新增）

## 八、竞品与差异化

| 竞品 | 重合处 | 我们多什么 |
|---|---|---|
| Claude Code 官方 **Learning output style** | 写码时停下让你实现一小段、插 `TODO(human)` | 画板 / 沉浸模式 / 卡壳分档 / 跨 agent |
| **rodbv/socratic-skills**（quiz-me + guide-me） | 逐题验收、读 diff 检查、不给代码 | 卡壳三档 / 项目级作用域 / 复习调度 / 画板 |
| **Anki / SuperMemo** | 间隔重复 | **自动把错题变成复习项**（Anki 要手动制卡）——这是真正的差异化 |

**路线已定：甲**——自己实现，不依赖外部包（硬约束 2）。但吸收 quiz-me 的具体机制：出题判据（「不能靠复制粘贴源文件一行字回答」）、题型库、追问句式（「你说了 X——那 Y 边界情况呢，你的答案还成立吗」）、模糊回答检测（说「更高效」要追问具体）。
